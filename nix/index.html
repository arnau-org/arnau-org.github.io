$ man nixos

Comandes repetitives per treballar amb NixOS: aplicar canvis, actualitzar el flake, gestionar generations i diagnosticar quan alguna cosa falla.

01Rebuild

Aplicar canvis del configuration.nix/home.nix ara mateix i a l'arrencada
sudo nixos-rebuild switch --flake /etc/nixos
Amb una sola nixosConfigurations al flake no cal indicar el nom després de #.
Aplicar només al proper arrencada, sense tocar la sessió activa
sudo nixos-rebuild boot --flake /etc/nixos
Provar sense crear una generation nova (es perd al reiniciar)
sudo nixos-rebuild test --flake /etc/nixos
Tornar enrere immediatament si un rebuild ha deixat el sistema pitjor
sudo nixos-rebuild switch --rollback

02Actualitzar

Flux complet: fixar noves versions i aplicar-les
cd /etc/nixos
sudo nix flake update                              # 1. actualitza flake.lock
git diff flake.lock                                # 2. (opcional) revisa què canvia
sudo nixos-rebuild switch --flake /etc/nixos       # 3. aplica
nixos-rebuild switch sol NO actualitza res — sempre fa servir les versions ja fixades al flake.lock.
Actualitzar només un input concret (per exemple, caelestia-shell)
sudo nix flake lock --update-input caelestia-shell

03Generations

Vull...Comanda
Llistar-les totessudo nix-env --list-generations -p /nix/var/nix/profiles/system
Esborrar >14 diessudo nix-collect-garbage --delete-older-than 14d
Esborrar totes menys l'activasudo nix-collect-garbage -d
Esborrar-ne una en concret (núm. 3)sudo nix-env -p /nix/var/nix/profiles/system --delete-generations 3
Regenerar el menú de bootsudo /run/current-system/bin/switch-to-configuration boot
Compte: esborrar generations elimina la possibilitat de fer rollback a elles. No ho facis just després d'un rebuild dubtós.

04Depurar

Traça completa quan un error d'evaluació és massa curt
sudo nixos-rebuild switch --flake /etc/nixos --show-trace
Veure quins paquets/outputs exposa un flake abans de fer-lo servir
nix flake show github:usuari/repositori
Útil per confirmar si un mòdul és homeModules o homeManagerModules abans d'endevinar-ho.
Logs d'un servei que no arrenca (greetd, pipewire, NetworkManager...)
journalctl -xe
journalctl -u nom-del-servei -b
Recarregar Hyprland sense reiniciar sessió, després d'editar hyprland.lua
hyprctl reload

05TTY de rescat

Per quan Hyprland es queda penjat i no hi ha manera d'obrir cap terminal.

1. Sortir a una consola de text
Ctrl + Alt + F2
Si F2 no respon, prova F3–F6.
2. Iniciar sessió amb usuari/contrasenya normal, i matar Hyprland
pkill Hyprland
# si no respon:
pkill -9 Hyprland
3. Tornar a la sessió gràfica un cop arreglat
Ctrl + Alt + F1

06Neteja del sistema

Neteja completa: garbage collect + optimitzar el store
sudo nix-collect-garbage --delete-older-than 14d
sudo nix-store --optimise
Veure quant espai alliberaries abans de confirmar res
nix-store --gc --print-dead

07Caelestia

Arrencar el shell manualment (ja hauria de fer-ho sol via hyprland.lua)
caelestia shell -d
Netejar notificacions acumulades si el shell va lent en carregar
caelestia shell notifs clear
On van les personalitzacions (només amb caelestia-shell sol, sense els dots complets)
mkdir -p ~/.config/caelestia
nano ~/.config/caelestia/shell.json
FitxerConté
~/.config/hypr/hyprland.luaConfig completa de Hyprland — és teva, no la toca el shell
~/.config/caelestia/shell.jsonVPN, mòduls del dashboard, providers
Important: aquest shell.json NO es crea per defecte — cal crear-lo tu manualment. Sense ell, el shell simplement fa servir tots els valors per defecte (per això el directori ~/.config/caelestia/ pot no existir fins que en creïs un).

08WireGuard

Connectar / desconnectar manualment (sense NetworkManager)
sudo wg-quick up wg0
sudo wg-quick down wg0
No facis systemctl enable wg-quick@wg0 — això el deixaria actiu permanentment a l'arrencada.
Veure l'estat de la connexió
sudo wg show
Alternativa amb NetworkManager (toggle des de nmtui/GUI, i necessari pel toggle de Caelestia)
sudo nmcli connection import type wireguard file /etc/wireguard/wg0.conf
sudo nmcli connection modify wg0-client connection.autoconnect no
nmcli connection up wg0-client
nmcli connection down wg0-client
